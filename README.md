## 🚀 Features

- **⚡ Multimodal Vision AI**: Accurately inspects image subjects, colors, perspectives, angles, lighting, and backgrounds to generate high-converting SEO titles and 45+ stock tags.
- **🛡️ 100% Agency Compliance**: Automatic anti-trademark sanitization, spam keyword filtering, and Adobe Stock title rules (no trailing period, prioritized top tags).
- **🔒 100% Client-Side Privacy**: Direct browser-to-API communication with zero backend server storage of your images.
- **🐬 Multi-Provider AI Support**:
  - **OrcaRouter** (`orcarouter/fusion-flash` - High Speed Multimodal)
  - **Google Gemini** (`gemini-2.0-flash` / `gemini-1.5-flash` - Native Vision)
  - **Groq Cloud API**
  - **OpenAI Vision**
- **📦 1-Click Platform CSV Export**:
  - Adobe Stock
  - Shutterstock
  - Freepik
  - Vecteezy
  - 123RF
  - Canva
  - iStock / Getty
  - Pond5
  - Depositphotos
  - General Microstock CSV
  - All-in-one ZIP download (all 10 templates formatted simultaneously)
- **🎨 Modern UI & Experience**:
  - Inter typography & warm brand gradient palette (`#ff2d7a` ➔ `#ff4b3e` ➔ `#ff6a1a`)
  - Skeleton shimmer loading animations
  - Colorful confetti celebration on 100% queue completion

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/lakshithamadumal/MetaDataGen.git
cd MetaDataGen
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
